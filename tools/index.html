OCR Rater UI Static · github.io

Pure client-side rater for the P1 garment-OCR accuracy study. 80 items, four conditions (A / B / C / D), three judgements per item (correct / incorrect / skip). Progress and answers live in the rater's browser; export is a single JSON file the rater emails back. No backend, no account, no tracking.

Public URL: https://iamtamilore.github.io/rater/ Per-rater URLs: ?rater=<id>&token=<32-char secret>
Open rater UI mint.py (CLI for per-rater URLs)
For raters: the URL I send you already has your ?rater= and ?token= filled in. Bookmark it — that is the recovery path if you close the tab. When you finish, click "Download my ratings (JSON)" and send the file back.

Image Generator (Mohit's UI) Live · Tailscale funnel

Flask app for the image-generation experiment — prompt, four conditions (A no-asset / B reference / C edit / D edit-with-reference), gallery of generated images, OCR accuracy feed. Used by the second author of the study to run the conditions end to end and inspect outputs without leaving the experiment folder.

Public URL: https://newtazer.tail1075c4.ts.net/ Backing: Flask on :8763 behind Tailscale funnel
Open generator
How it's served: the funnel proxies to a small reverse router on localhost (:9000) that forwards / to the Flask UI and /garments/, /audition/, /uploads/ to the asset ref-server (:8799) so kie.ai can fetch local references. The top-right of the generator now has a "back to hub" link to this page.
