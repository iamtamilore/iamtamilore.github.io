Workflows

ask.py blueprint recipes I actually run

Recipe 01

Generate a 60-second short-form anime episode

qwen3-vl-235b (select) / qwen-image (stills) / gpt-audio (narration) / ffmpeg (assembly)

  1. Source 50 candidate frames per shot-need from kie.ai, scoped per beat
  2. Score each candidate with qwen3-vl against the brief's NEVER rules
  3. Pick top 12-14 stills per episode, crop to 1080x1920
  4. Generate narration via gpt-audio, time-stamp against the beat structure
  5. Assemble with ffmpeg, hard-cuts on narration, one yellow word per shot

~ 1.50 USD inbound, 0.5 credits outbound per episode

Recipe 02

Capture a hero image from a real reference

flux-2/pro-image-to-image

  1. Pass the reference as the only input_url, no other text
  2. Prompt for natural skin texture, visible pores, no retouching
  3. Set resolution 1K, nsfw_checker false, aspect_ratio 3:4
  4. Generate best-of-5, pick the lock, never the prettiest
  5. Verify EMB_SIM against the reference (target above 0.98)

~ 5 credits per capture, EMB_SIM 0.9906 vs 0.9802 on the benchmark

Recipe 03

Edit a product photo on a reference

gpt-image-2-image-to-image, quality high

  1. Subject ref first, garment or product ref second, plain prompt
  2. No cropped detail ref, no colour swatch, no colour-naming
  3. Set aspect_ratio to target surface, 3:4 for cards, 1:1 for thumbnails
  4. Keep negatives light, aggressive negatives cause drift on this model
  5. Best-of-5, verify text and product match by eye, OCR lies

~ 6 credits per edit, text-in-image and complex multi-ref both clean

Recipe 04

Score a contact sheet of stills

qwen3-vl-235b via OpenRouter

  1. Compose 16-22 stills into one contact sheet at 768px wide
  2. Send image plus brief's per-frame rules in the same prompt
  3. Ask for one-line verdict per frame plus a single overall verdict
  4. Reject if "NO VERDICTS" returned, usually means per-need queries were identical
  5. Keep verdicts as text, never rely on the model's confidence score

0 USD per call on OpenRouter, rate-limit the only real constraint
