TermsGuard AI

Live demo →

Reads the small print in privacy policies and flags the parts that are unfair to you.

Failure mode it prevents: a clause being labelled "checked by the model" when no model had actually looked at it. The previous build did that, silently. The current build runs the verifier on three routing paths with retry and surfaces any fallback as an error.

Headline: 102 hand-labelled reference clauses (52 fair, 50 unfair). 4,527 chunks of retrieval context. Up to 15 flagged clauses go to Claude for verification per analysis. Verified by a 12-case regression suite measured live on 25 October 2026.

Honest limit: the retrieval index is mostly data-governance and GDPR context, only about 2 percent of it cites a GDPR article. The tool surfaces context, not regulation.

Customer Care Process Automation

Full write-up →

Two bots that took over two jobs I used to do by hand every morning at Huawei.

Failure mode it prevents: a complaint being forced through to a team the classifier was unsure about. Below 0.55 confidence the ticket goes to a human instead of being routed.

Headline: TF-IDF + Naive Bayes routes complaints to five back-end teams. 95.2% accuracy on 42 held-out tickets. Both errors were P_BILL and REFUND confusion, the one boundary the model cannot tell apart.

Honest limit: 42 tickets is a thin evaluation. The 0.55 escalation threshold was set by judgement about the cost of a needless escalation, not swept.

Smart Medical Records Engine

Full write-up →

A doctor asks in plain English and gets the answer out of the patient's own file.

Failure mode it prevents: the wrong patient's note being returned because it happens to be worded the same way. The retrieval query carries the patient_id, and the database filters on it before ranking.

Headline: self-hosted on the hospital's own machine. PII stripped pre-embedding. 30 adversarial probes designed to leak cross-patient. Zero leaked.

Honest limit: designed and tested on synthetic records, not a hospital deployment. A real deployment is integration work, not model work.

Image QA Gate (private until graded)

Full write-up →

Catches the moment an AI-generated model stops being the same person.

Failure mode it prevents: a quality gate that cries wolf. A gate that flags good images gets switched off within a week. Zero false acceptances was the target, not a bonus.

Headline: Siamese network over frozen ResNet50 features. F1 0.90, ROC-AUC 1.00, precision 1.00 on 90 sealed test pairs. Two baselines lose: pixel difference at F1 0.59, kNN at F1 0.26.

Honest limit: 90 pairs is too few to rule out luck as the explanation for the gap to the baselines. McNemar's test is underpowered.
