TermsGuard AI

Reads the small print in a privacy policy and flags the unfair parts.

Failure mode it prevents
A clause being labelled "checked by the model" when no model actually looked at it. The previous build did that, silently.
Cost of being wrong
Telling you your bank's terms are predatory when they are not. A bad warning is worse than no warning, because you stop reading the ones that matter.
Headline number
102 hand-labelled reference clauses (52 fair, 50 unfair). 4,527 chunks of retrieval context. A 12-case regression suite runs against the deployed service and currently passes 12 of 12 live.
Honest limit
The retrieval index is mostly data-governance and GDPR context. About 2% of it cites a GDPR article. The tool surfaces context, not regulation.

Customer Care Process Automation

Two bots that took over two jobs I used to do by hand every morning at Huawei.

Failure mode it prevents
A complaint being forced through to a team the classifier was unsure about. Below 0.55 confidence the ticket goes to a human instead of being routed.
Cost of being wrong
A misrouted complaint costs the customer days of waiting. A needless escalation costs an agent five minutes. Wildly lopsided, so the gate is set to escalate freely.
Headline number
95.2% accuracy on 42 held-out tickets. Both errors were P_BILL and REFUND confusion, the one boundary the model cannot tell apart.
Honest limit
42 tickets is a thin evaluation. The 0.55 escalation threshold was set by judgement about the cost of a needless escalation, not swept.

Smart Medical Records Engine

A doctor asks in plain English and gets the answer out of the patient's own file.

Failure mode it prevents
A different patient's note being returned because it happens to be worded the same way. The retrieval query carries the patient_id, and the database filters on it before ranking.
Cost of being wrong
A data breach, and possibly a wrong prescription. Too expensive to leave to a threshold, so this system has no dial in it at all. The failure is designed out at the query, not tuned down afterwards.
Headline number
30 adversarial probes designed to leak cross-patient data, zero leaks. Self-hosted on the hospital's own machine. PII stripped pre-embedding.
Honest limit
Designed and tested on synthetic records, not a hospital deployment. A real deployment is integration work, not model work.

Image QA Gate (private until graded)

Catches the moment an AI-generated model stops being the same person.

Failure mode it prevents
A quality gate that cries wolf. A gate that flags good images gets switched off inside a week, and then it is protecting nobody.
Cost of being wrong
The wrongly accepted image, not the missed one. Zero false acceptances was the target, not a bonus.
Headline number
F1 0.90 on 90 sealed test pairs. ROC-AUC 1.00, precision 1.00. Two baselines lose: pixel difference at F1 0.59, kNN at F1 0.26.
Honest limit
90 pairs is too few to rule out luck as the explanation for the gap to the baselines. McNemar's test is underpowered.
