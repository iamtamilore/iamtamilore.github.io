O.A.P. Trainer

1,217 social-dynamics examples mined from 796 YouTube videos. Spaced repetition with SM-2 scheduling and AI-generated practice scenarios. Built because I needed a training system that did not exist.

Checking local system...

What it does

The O.A.P. Trainer is a spaced-repetition system for social-dynamics patterns. It pulls examples from a library of 1,217 mined interactions, schedules them with SM-2, and generates new practice scenarios through an LLM when you need fresh material. Every scenario costs an API call, so the system is gated by your own usage.

How it is built

  • Backend FastAPI on localhost:8000
    Seven endpoints, CORS enabled, no authentication. SQLite database on the laptop's internal disk. Works with no external drive.
  • Scheduling SM-2 algorithm
    Cards due today are surfaced first. Rating a card updates its interval and ease factor. The algorithm is deterministic and auditable.
  • Scenarios LLM-generated on demand
    When the library does not cover a situation, the system generates a scenario, scores your response against rubrics, and stores the result. Each generation costs one LLM call.
  • Data SQLite, local only
    The 1,217 examples and your practice history live in a SQLite file on your laptop. No cloud sync, no export, no backup. If the laptop dies, the data dies with it. That is a deliberate choice for a personal training tool.

Why it is not on the internet

Three reasons, in order of importance:

  1. It spends money. Every scenario generation calls a paid LLM. Exposing this to the internet would be exposing a metered resource.
  2. It has no authentication. The FastAPI backend has CORS on and no auth layer. Adding auth would mean secrets, sessions, and attack surface for a tool only I use.
  3. It is personal. The examples are mined from content I watched and judged relevant. The practice history is mine. There is no reason for this to be public data.

This page exists so you know the system exists. The UI below shows what you would see if you were sitting at my laptop with the backend running. When the laptop is off, it is disabled. That is the normal state.
