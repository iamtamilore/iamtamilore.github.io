How I work

  1. Establish the baseline before training anything. A model that cannot beat a simple guess does not deserve to exist.
  2. Name the error you can afford before choosing a threshold. Rejecting a good image costs one retry; accepting a bad one sends it to the client.
  3. Model the process in BPMN before writing code. Draw the process on paper before coding it. The automation should replace what actually happens, not what you think happens.
  4. Freeze the preprocessing with the model so the way you prepare data in training stays the same in production.
  5. Version every artefact so you can roll back a bad release instead of spending hours figuring out what broke.
  6. State what breaks, in writing, next to what works. Every project page says what can go wrong before it says what works.
